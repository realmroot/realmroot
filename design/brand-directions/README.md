# Realmroot design-system comparison

This artifact compares six visually distinct systems using the same information
architecture and HTML structure across Console, Hosted Auth, and Account Center.

Open `index.html` directly, or serve the repository and visit
`/design/brand-directions/`.

## Shared brand foundation

- Descriptor: `Identity and delegated access for people, apps, and agents.`
- Brand line: `One realm. Every actor. Explicit authority.`
- Supporting line: `Your product's identity root.`

## A. Grid Blue

- Color: system blue `#075FE4`, white, ink `#071221`
- Navigation: white rail with blue inset indicator
- Geometry: 2–6px radius
- Surface: thin blue-gray borders, no shadow
- Type: Swiss sans with monospace protocol labels
- Character: rational, precise, tool-like

## B. Vermilion Signal

- Color: vermilion `#D33A18`, charcoal, white
- Navigation: neutral rail with a filled vermilion selection
- Geometry: 6–12px radius
- Surface: white canvas, neutral borders, no shadow
- Type: direct system sans
- Character: decisive, explicit, action-oriented

## C. Clear Aqua

- Color: aqua `#007B83`, charcoal, white
- Navigation: near-white rail with a filled aqua selection
- Geometry: 10–18px radius
- Surface: white canvas, neutral borders, restrained elevation
- Type: calm system sans
- Character: clear, open, composed

## D. Solar Authority

- Color: solar yellow `#FFD43B`, accessible ochre `#765600`, white
- Navigation: neutral rail with a yellow selection and dark text
- Geometry: 4–10px radius
- Surface: white canvas, neutral borders, no shadow
- Type: precise system sans
- Character: visible, optimistic, authority-forward

## E. Iris Frame

- Color: iris `#643AE8`, lavender frame, white
- Navigation: white rail with outlined violet selection
- Geometry: 7–14px radius
- Surface: visible violet borders, no shadow
- Type: precise system sans
- Character: bounded, distinct, modern

## F. Matcha Root

- Color: matcha `#587A35`, near-white `#F8FAF8`, charcoal `#172018`
- Navigation: neutral near-white rail with a solid matcha selection
- Geometry: 7–14px radius
- Surface: white content canvas, neutral borders, restrained elevation
- Type: calm system sans with compact infrastructure labels
- Character: fresh, restrained, quietly trustworthy

## Comparison constraint

All six systems use the same product content and macro layout. Differences are
implemented through color distribution, typography, geometry, borders,
elevation, navigation state, and component treatment. No direction is written
to the production `DESIGN.md` until selected.
