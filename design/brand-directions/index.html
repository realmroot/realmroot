如何选择

不是选颜色，是选第一印象

方向用户第一感受最适合风险
A · Grid Blue理性、精确、工具化Console / API / 文档品牌情绪最克制
B · Vermilion Signal果断、清晰、有行动感Console / 管理操作需与危险状态严格区分
C · Clear Aqua清透、冷静、开放跨 Console 与 Hosted Auth需避免普通企业青色
D · Solar Authority鲜明、乐观、权限可见Agent / Delegation / Console黄色必须搭配深色文字
E · Iris Frame独立、边界明确、现代统一主品牌与产品框架必须避免 AI 紫色渐变
F · Matcha Root清爽、沉静、有秩序跨 Console、Auth 与 Account品牌色必须保持低占比
